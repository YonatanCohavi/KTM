# Supabase Setup

This configures the optional online leaderboard. Without these settings, the app uses local storage.

## 1. Create a Supabase project

Create a project at [supabase.com](https://supabase.com) and wait for its database to finish provisioning.

## 2. Create the leaderboard table

In the Supabase dashboard, open **SQL Editor**, create a query, and run:

```sql
CREATE TABLE IF NOT EXISTS public.leaderboard (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  browser_uuid TEXT UNIQUE NOT NULL,
  player_name TEXT DEFAULT '',
  level INTEGER NOT NULL DEFAULT 1,
  xp INTEGER NOT NULL DEFAULT 0,
  streak INTEGER NOT NULL DEFAULT 0,
  updated_at TIMESTAMPTZ NOT NULL DEFAULT CURRENT_TIMESTAMP
);

ALTER TABLE public.leaderboard
  ADD COLUMN IF NOT EXISTS player_name TEXT DEFAULT '';

CREATE INDEX IF NOT EXISTS idx_leaderboard_level_xp
  ON public.leaderboard(level DESC, xp DESC);

ALTER TABLE public.leaderboard ENABLE ROW LEVEL SECURITY;

DROP POLICY IF EXISTS "Allow public read" ON public.leaderboard;
CREATE POLICY "Allow public read" ON public.leaderboard
  FOR SELECT USING (true);

DROP POLICY IF EXISTS "Allow insert/update" ON public.leaderboard;
CREATE POLICY "Allow insert/update" ON public.leaderboard
  FOR INSERT WITH CHECK (true);

DROP POLICY IF EXISTS "Allow update own entry" ON public.leaderboard;
CREATE POLICY "Allow update own entry" ON public.leaderboard
  FOR UPDATE USING (true) WITH CHECK (true);
```

The statements also work for an existing leaderboard table and add the `player_name` column if it is missing.

## 3. Configure the app

In the project root, create `.env.local` and add the project URL and publishable (formerly `anon`) key. Find both under **Project Settings → API Keys** in Supabase.

```dotenv
VITE_SUPABASE_URL=https://YOUR_PROJECT_ID.supabase.co
VITE_SUPABASE_ANON_KEY=YOUR_PUBLISHABLE_KEY
```

Restart the Vite server after changing environment variables:

```sh
pnpm dev
```

For deployment, set the same two variables in the hosting provider's environment settings and rebuild the app.

## Security note

The publishable key is intended to be used in browser code. Never put a `service_role` or secret key in a `VITE_` variable. The policies above allow any visitor to insert or update leaderboard rows, and the app currently sends scores from the browser, so this setup does not prevent score tampering.
